# Commit rules


## Règles des commits

- **feat** : Utilisé pour l'ajout d'une nouvelle fonctionnalité.
- **fix** : Utilisé pour la correction d'un bug.
- **docs** : Utilisé pour les modifications de documentation.
- **style** : Utilisé pour les changements de formatage, de style de code, etc., qui n'affectent pas le fonctionnement du code.
- **refactor** : Utilisé pour les modifications de code qui n'ajoutent pas de fonctionnalité et ne corrigent pas de bug (ex : refactorisation de code).
- **perf** : Utilisé pour les changements de code qui améliorent les performances.
- **test** : Utilisé pour l'ajout ou la modification de tests.
- **chore** : Utilisé pour les tâches de maintenance qui ne modifient ni le code source ni les tests (ex : mise à jour des dépendances et autres).
