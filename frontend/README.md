# Projet Android : Recettes UGE - ForkEat

Bienvenue dans le projet Android "Recettes UGE - ForkEat". Ce projet est une application mobile dédiée à la gestion et au partage de recettes culinaires, développée dans le cadre de cours d'Android à l'Université Gustave Eiffel (UGE).

## Architecture du Projet

![Architecture du Projet](readme_images/architecture.png)

Les principales composantes de l'application sont les suivantes :

- **Features** : Contient les différentes fonctionnalités de l'application, telles que la gestion des recettes, des utilisateurs, de l'admin, etc.
- **Data** : Contient les sources de données, y compris les API, les bases de données locales, et les modèles de données.
- **Core** : Contient les composants réutilisables et les utilitaires partagés à travers l'application.
